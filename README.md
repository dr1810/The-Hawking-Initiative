# The-Hawking-Initiative
An assistive technology application for people with disabilities, helps people with special needs

## How to run the Application

Step 1: Clone the repository

Step 2: Activate the virtual environment
```bash
source .venv/bin/activate
```

Step 3: Enter the BaseUI directory
```bash
    cd BaseUI
```

Step 4: Run the streamlit command
```bash
   streamlit run main.py
```

Step 5: View the Application using the localhost link in your terminal

## How to view the Base UI Specification built using Tkinter

Step 2: Activate the virtual environment
