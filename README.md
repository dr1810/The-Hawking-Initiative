# The-Hawking-Initiative
An assistive technology application for people with disabilities, helps people with special needs

How to run the Application

Step 1: Clone the repository

Step 2: Enter the BaseUI directory

        ```bash
        cd BaseUI
        ```

Step 3: Run the streamlit command
        ```bash
        streamlit run main.py
        ```

Step 4: View the Application using the localhost link in your terminal
